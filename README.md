## 📋 Project Overview

This project analyzes customer behavioral and financial data to identify early churn and risk indicators. It spans the entire data science lifecycle—from initial stakeholder communication to hyperparameter tuning and model evaluation. 

Designed to mirror real workflows used by top-tier consulting teams, this project demonstrates how to deliver actionable, data-driven analytical solutions.

### 🔑 Key Pipeline Stages
1. **Exploratory Data Analysis (EDA)**
2. **Data Preprocessing & Cleaning**
3. **Feature Engineering of Risk Drivers**
4. **Predictive Modeling** (Random Forest Framework)
5. **Hyperparameter Tuning**
6. **Business Insights & Recommendations**

---

## 📂 Repository Structure & Workflow Tasks

The repository is structured to reflect progressive consulting deliverables, mirroring the tasks delivered to a Senior Data Scientist.

### 📄 Task 1 — Strategy & Business Communication
**Filename:** `Utility_Customer_Churn_Analytics_Strategy.md` (or `.pdf`)
*   **Purpose:** Professional written communication establishing the project foundation.
*   **Includes:** Problem understanding, assumptions, risk identification, defined deliverables, and strategic next steps.

### 📓 Task 2 — EDA & Data Cleaning
**Filename:** `Foundational_Data_Analysis_for_Churn_Modeling.ipynb`
*   **Analysis Conducted:** Univariate, bivariate, and multivariate analysis; Distribution analysis of numerical & categorical variables; Correlation heatmaps.
*   **Data Integrity:** Missing value imputation, Outlier detection, Pattern recognition.
*   **Cleaning Pipelines:** End-to-end pipelines including imputation, encoding, and scaling.
*   **Tech Stack:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

### 📓 Task 3 — Feature Engineering
**Filename:** `Advanced_Feature_Engineering_for_Churn_Prediction.ipynb`
*   **Risk Feature Creation:** 
    *   Billing volatility & usage anomalies
    *   Arrears & payment delays
    *   Auto-pay dropout behavior
    *   Plan-change frequency
*   **Methodology:** Advanced feature transformations, automated feature selection methods, robust encoding, and scaling techniques.
*   **Tech Stack:** `scikit-learn`, `feature_engine`, `pandas`

### 📓 Task 4 — Predictive Modeling & Optimization
**Filename:** `RandomForest_Performance_Optimization_Framework.ipynb`
*   **Modeling Engine:** Custom `RandomForestClassifier` pipeline.
*   **Optimization:** Comprehensive hyperparameter tuning utilizing `GridSearchCV`.
*   **Evaluation:** Recall-focused evaluation methodology (critical for risk prediction).
*   **Outputs:** Confusion matrix, feature importance visualizer, and detailed risk-segment profiling.
*   **Tech Stack:** `RandomForestClassifier`, `GridSearchCV`, `classification_report`, `recall_score`
